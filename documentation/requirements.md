# System Requirements

## Functional Requirements

### Student Management
- Add student
- View student
- Search student
- Update student
- Deactivate student

### Faculty Management
- Add faculty
- View faculty
- Search faculty
- Update faculty
- Deactivate faculty

### Department Management
- Add department
- View department
- Update department

### Attendance
- Record attendance
- View attendance
- Calculate attendance percentage
- Identify students below 75%

### Fees
- Record fee payment
- View payment status
- Calculate outstanding fees

### Examinations
- Record marks
- Calculate results
- Calculate pass percentage
- Generate department-wise performance

### Dashboard
- Display key institutional KPIs
- Display department statistics
- Display attendance trends
- Display fee collection
- Display examination performance

## User Roles

### Administrator
Full access to institutional data.

### Faculty
Access to assigned academic and attendance functions.

### Management
Read-only access to reports and dashboards.
